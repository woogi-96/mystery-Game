### 입장 비밀번호

처음 들어오면 숫자 4자리 비밀번호를 정해요(두 번 눌러 확인). 그 기기에서는 다음부터 비밀번호 없이 바로 들어오고, 다른 기기에서 처음 열 때만 입력해요.
- claude.ai 페이지: 사람마다 자기 비밀번호를 정하고, 본인만 볼 수 있는 곳에 암호화(해시)해서 저장해요. 잊으면 잠금 화면에서 다시 정할 수 있어요.
- 서버 방식: 모두가 같은 비밀번호를 써요. 5번 틀리면 1분 동안 잠겨요. 관리자 화면에서 초기화할 수 있어요.

### 관리자 페이지 (주소 분리)

- 일반 주소: 사이트 주소 그대로 (`index.html`)
- 관리자 주소: 주소 끝에 **`#admin`** (예: `https://claude.ai/artifact/…#admin`, `http://localhost:3000/#admin`)
- 일반 화면에는 관리자 링크가 없어요. claude.ai 에서는 이 페이지를 편집할 수 있는 사람(주인, 편집자)만, 서버 방식에서는 관리자 비밀번호를 아는 사람만 들어갈 수 있어요.

관리자 기능: 멍뭉이 일기 확인 후 **💮 참 잘했어요 발바닥 도장** 찍기(글 옆에 도장, 멍뭉이 화면 달력과 오늘의 멍뭉에도 표시, 도장 1개당 성장 +5), 일기·사진·도장·소개서 개별/전체 **데이터 삭제**, 소개서 특징 목록 편집, 비밀번호 변경, 전체 데이터 백업(JSON).
기본 비밀번호는 **`meongmung`** 입니다. 처음 들어가면 꼭 바꿔 주세요.

## 실행 방법

> 📱 **로그인 없이 휴대폰 브라우저로 열기**: [SETUP-ONLINE.md](SETUP-ONLINE.md) (Netlify + Supabase, 무료)

### 0) claude.ai 페이지 (휴대폰에서 바로)

claude.ai 에 올린 페이지로 열면 claude.ai 공용 저장소를 써서, 페이지를 공유받은 사람끼리 같은 일기·사진·소개서를 봐요. 관리자 메뉴는 그 페이지를 편집할 수 있는 사람(주인, 편집자)에게만 열려요.

### 1) 서버로 실행 (추천: 둘이 같은 데이터를 봐요)

Node.js 18 이상이면 되고, 따로 설치할 패키지는 없습니다.

```bash
cd diary
npm start                       # http://localhost:3000
# 포트 / 처음 비밀번호 지정
PORT=8080 ADMIN_PASSWORD=원하는비번 npm start
```

- 데이터는 `diary/data/db.json`에, 사진은 `diary/data/uploads/`에 저장됩니다. (`data/` 폴더는 git에 올라가지 않아요)
- `ADMIN_PASSWORD`는 처음 실행할 때만 쓰입니다. 그 뒤로는 관리자 페이지에서 바꾼 비밀번호를 씁니다. 잊어버렸다면 `RESET_PASSWORD=1 ADMIN_PASSWORD=새비번 npm start`로 다시 정할 수 있습니다.
- 휴대폰으로 보려면 Render, Railway, Fly.io 같은 Node 호스팅에 `diary` 폴더를 올리고 시작 명령을 `npm start`로 하면 됩니다. 저장소(디스크)가 유지되는 곳을 쓰고, 필요하면 `DATA_DIR` 환경 변수로 저장 위치를 정하세요.

### 2) 정적 호스팅 (GitHub Pages 등)

서버가 없으면 자동으로 **이 브라우저에만 저장**하는 모드로 동작합니다(IndexedDB). 혼자 써 보기에는 좋지만, 다른 기기나 다른 사람과는 데이터가 공유되지 않습니다. 화면 맨 아래에 지금 어떤 모드인지 표시됩니다.

## 파일 구조

```
diary/
├─ index.html        사이트 (4개 메뉴)
├─ admin.html        관리자 페이지
├─ server.js         Node 서버 (API + 정적 파일)
├─ css/diary.css
├─ js/
│  ├─ app.js         사이트 화면
│  ├─ admin.js       관리자 화면
│  ├─ store.js       저장소 (서버 API ↔ 브라우저 저장 자동 전환)
│  ├─ defaults.js    기본 프로필 · 특징 목록
│  ├─ scene3d.js     3D 인사 장면 (Three.js, 멍뭉이와 멍뭉네 집)
│  ├─ greeting.js    시간대 인사
│  ├─ lock.js        입장 비밀번호 잠금 화면
│  ├─ places.js      함께 다녀온 곳
│  ├─ growth.js      성장 점수 · 레벨 · 꿀팁
│  ├─ character.js   캐릭터 이미지, 발바닥 도장
│  └─ lib/           three.module.js
└─ assets/           멍뭉 캐릭터 일러스트, 파비콘
```

## 참고

- 맨 아래 "개인정보 수집·이용 안내"는 일반적인 고지 문안이에요. 실제로 여러 사람에게 공개 운영한다면 보호책임자 연락처 등을 채우고 필요하면 전문가 확인을 받아 주세요.

- 사이트(일기 쓰기, 사진 올리기, 소개서 저장)는 주소를 아는 사람이면 누구나 쓸 수 있습니다. 삭제와 특징 목록 관리는 관리자만 할 수 있어요.
- 3D가 안 되는 기기에서는 일러스트로 대신 인사합니다.
