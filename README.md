# 멍뭉의 꿈 미스터리 🐶💤

퇴근하고 지친 **멍뭉**이가 잠든 뒤, 꿈속 다섯 개의 사건을 추리 퀴즈로 풀어내는 **3D 웹 어드벤처 게임**입니다.
모든 퀴즈를 풀면 "알고 보니 다 꿈이었다!" 하고 **우기**와 데이트를 떠나고, 실패하면 꿈에 갇혀 우기가 깨워 줍니다.

![캐릭터 레퍼런스](assets/reference.png)

> 🐾 **멍뭉일지** (멍뭉이의 하루를 기록하는 모바일 웹사이트 + 관리자 페이지)는 [`diary/`](diary/README.md) 폴더에 있습니다.

## 실행 방법

빌드 과정이 없는 정적 웹페이지입니다. (Three.js는 `js/lib`에 포함)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> ES 모듈을 쓰기 때문에 `index.html`을 파일로 바로 열면 동작하지 않습니다. 반드시 로컬 서버로 열어 주세요.
> GitHub Pages에 그대로 올려도 동작합니다.

## 게임 흐름

하루의 흐름을 따라 꿈이 이어집니다: **대학교 → 집 가는 길 공원 산책 → 오후 출근 → 버스 퇴근 → 집**

0. **프롤로그**: "어느 도시의 밤, 멍뭉이라는 사람이 살고 있었다…" 내레이션으로 멍뭉과 우기를 소개하는 오프닝 애니메이션 (건너뛰기 가능)
1. **방 (현실)**: 시간이 빠르게 흐르는 연출 → 퇴근한 멍뭉 등장 → **누워 잔다 / 누군가에게 전화한다** 선택
2. **꿈 1 · 대학교**: 출석 부르기(대답 / 자는 척) → 환경사회학(공유지의 비극) → 돌발: 탄소중립 → 환경경제학(리바운드 효과) → 동아리방 넌센스 퀴즈 대회(간식 선택, 돌발 넌센스)
3. **꿈 2 · 공원**: 집 가는 길 산책 → 관리인 아저씨와 동굴로(손전등 선택) → 생각이 필요한 문제: 세 갈래 길 / 물의 저울 문 / 네 개의 문, 돌발: 종유석
4. **꿈 3 · 회사**: 오후 출근 → 업무 퀴즈: 우선순위 정하기 / LA 회의 시차 계산, 커피 선택, 돌발: ASAP → 야근 중 정전(메일 선택) → 계단 인원 점검
5. **꿈 4 · 버스**: 퇴근 버스(우기에게 문자 / 음악 선택, 돌발: 버스 전용차로 색) → 기사님이 쓰러짐 → 버스 정차 / 저혈당 응급조치 / 집까지 경로 찾기 → 아파트 앞에서 기다리던 우기와 인사
6. **꿈 5 · 아파트(집)**: 바로 잘지 게임할지 선택 → 새벽 2시, 돌발: 피자 박스 분리수거 → 경비 아저씨와 함께 수상한 1004호 이웃의 정체 추리
7. **엔딩**: 우리 집 현관문을 열면 아침 → "알고 보니 다 꿈이었다" → 우기와 데이트, 꿈 이야기 옹알옹알 💗 → 게임 다시 시작하기 / 게임 끝내기
   / 하트 소진 → "꿈에 갇힘" → 우기가 와서 깨워 줌 (해당 꿈부터 재도전)

## 퀴즈 진행 방식

- 퀴즈 화면이 따로 뜨지 않고, **등장인물들의 대화 속에서** 단서가 나옵니다. 누가 단서를 말할 때마다 카메라가 그 물건을 비춥니다.
- 대화 끝에 누군가 멍뭉에게 질문하면 **선택지 팝업**이 뜹니다. (📝 단서 메모로 들은 단서를 다시 볼 수 있음)
- 맞히면 질문한 사람이 이유(인과관계)를 설명해 주고, 틀리면 하트 1개를 잃고 힌트를 들은 뒤 다시 고릅니다.
- 꿈마다 3문제, 꿈마다 하트 3개.
- **이어서 하기**: 꿈이 시작될 때마다 진행이 브라우저에 저장됩니다. 나갔다가 다시 들어오면 시작 화면에서 **이어서 하기**(마지막 꿈의 처음부터) 또는 **처음부터 하기**를 고를 수 있습니다.
- **3개의 꿈 (다시 하기)**: 해피엔딩에서 **게임 다시 시작하기**를 누르면 다음 판은 문제가 새로 바뀝니다(총 3판, 브라우저에 진행 저장). **게임 끝내기**를 누르거나 중간에 실패하면 같은 문제 구성이 유지됩니다.
- **문제마다 새 3D 장소**: 2·3번째 꿈에서는 대학교 강의·동아리방·동굴·회사 업무 문제마다 그 문제를 위해 만든 3D 장소(강가의 공장, 38도의 도시, 차 없는 날 대로, 딸기 화물 공항, 왕궁, 얼어붙은 연못, 스위치 방, 지하 강 나루터, 모래시계 방, 주사위 방, 몬티 홀 문, 케이크 연회장, 보안 관제실, 서버실, 브레인스토밍 회의실, A/B 테스트 실험실)로 이동해 인물들이 그 안에서 대화하고 문제를 풉니다. 끝나면 원래 장면으로 돌아옵니다. 회사 정전·버스·아파트는 같은 상황에서 질문만 바뀌므로 원래 장면을 그대로 씁니다. (`js/stages.js`)
- **엔딩**: 데이트 장소에서 멍뭉이가 우기에게 꿈 이야기를 옹알옹알 요약해 줍니다. 그 판에서 푼 문제 제목, 내가 고른 선택, 돌발 퀴즈 점수가 그대로 들어가고 우기의 맞장구도 판마다 달라집니다.
- **대화 속 선택**: 출석 대답, 간식, 커피 등 정답 없는 선택에 따라 대사와 반응이 달라집니다.
- **⚡ 돌발 퀴즈**: 장면과 관련된 짧은 문제가 갑자기 나오고 제한 시간 안에 골라야 합니다. 틀려도 하트는 그대로, 엔딩에 맞힌 개수가 나옵니다.
- **배경음악**: 밝고 잔잔한 오르골 음악을 WebAudio로 직접 합성합니다 (오른쪽 위 🔊 버튼으로 끄기).

## 캐릭터

레퍼런스 이미지(왼쪽 우기, 오른쪽 멍뭉)를 바탕으로 3D 치비 캐릭터를 코드로 모델링했습니다 (`js/characters.js`).

| | 멍뭉 | 우기 |
|---|---|---|
| 머리 | 갈색 바가지머리, 정수리 가운데 사과머리(민트 머리끈) | 검정 긴 생머리, 일자 앞머리 |
| 옷 | 크림색 후드티 (끈, 캥거루 주머니) | 회색 집업 + 노란 하트 지퍼, 검은 크로스백 끈 |
| 소품 | – | 노란 하트 지퍼 고리, 검은 크로스백 끈 |
| 표정 | 우기 쪽을 바라보며 턱 괴기 | 윙크 + 활짝 웃는 입, 두 손으로 볼 감싸기 |

얼굴(큰 눈, 속눈썹, 하이라이트, 볼터치 빗금, 입)은 캔버스에 그려 머리 표면에 입히고, 깜빡임·말하기·표정 변화 때마다 다시 그립니다.

조연(선생님, 학생, 동아리원, 회사 동료, 버스 기사, 승객, 구급대원, 경비원, 이웃)은 주인공보다 조금 어른 비율의 사람 체형입니다. 둥근 머리와 목, 어깨에서 허리로 이어지는 몸통, 엄지가 있는 손, 그려 넣은 얼굴(눈·눈썹·코·입)을 갖고, 옷에는 칼라, 넥타이, 단추, 블레이저 라펠과 교표, 주머니, 지퍼, 사원증, 반사띠, 명찰을 프린트로 입혔습니다. 서 있을 때 체중 이동과 고개 돌리기, 말할 때 끄덕임, 걸을 때 상체 흔들림이 들어가 있습니다.

## 폴더 구조

```
index.html          화면 레이아웃 (HUD, 대화창, 퀴즈 패널, 엔딩)
css/style.css       UI 스타일 (모바일 대응)
js/main.js          렌더러, 카메라, 씬 전환(꿈 소용돌이 워프), 게임 흐름
js/ui.js            대사(타자 효과), 선택지, 퀴즈/피드백, 자막, 페이드
js/quizzes.js       1번째 꿈 퀴즈 15문제 (단서, 정답, 인과 체인, 해설, 힌트)
js/variants.js      2·3번째 꿈 문제 은행 (판마다 쓸 문제는 main.js의 PICK)
js/stages.js        2·3번째 꿈 문제별 3D 장소 16곳
js/art.js           문제별 슬라이드·화이트보드 그림
js/characters.js    멍뭉·우기·NPC 3D 모델과 포즈/표정 애니메이션
js/audio.js         WebAudio 효과음 (외부 파일 없음)
js/util.js          트윈, 지오메트리 헬퍼, 캔버스 텍스처, 파티클
js/scenes/          prologue / room / school(대학교) / park(+동굴) / office / bus / apartment / ending
js/lib/             three.js r160 (+ RoundedBoxGeometry)
```

## 디버그용 URL 옵션

- `?view=2&shot=door&state=dark` : 특정 꿈 장면을 정지 화면으로 보기 (0=학교 … 4=아파트)
- `?ep=3` : 4번째 꿈(버스)부터 바로 플레이
- `?speed=4` : 연출 속도 배속
- `?round=2` : 3번째 꿈 문제로 플레이 (0~2)
